# Áudio

Pasta reservada para áudio ambiente e efeitos.

Candidatos para a próxima etapa:
- passos com variação por superfície (madeira, pedra, metal e concreto);
- vento e água do East River;
- reverberação do Grande Salão;
- ambiente abafado da biblioteca.

Nenhum áudio de terceiros está incluído nesta versão.
