## Emblema Per Ankh

`per-ankh.svg` é um vetor original do CASABROOKLIN, criado para representar visualmente a composição dos sinais egípcios de casa e vida (O1 + S34). É uma representação gráfica de projeto, não uma transcrição epigráfica certificada nem um asset retirado de terceiros. A tabela de sinais consultada em `kevinelliott/giza` serviu como referência de identificação dos caracteres; nenhum ficheiro de fonte foi copiado.
